A tiny chess engine in under 4 KB of Python: negamax with alpha-beta pruning, quiescence search, transposition table, killer moves, MVV-LVA capture ordering, null-move pruning and check extensions. It searches to a fixed node budget, never to a clock, so every move is deterministic.

## Run it

```sh
MAKEFUN_ENV_URL=<env-url> python3 -P -s main.py
```
